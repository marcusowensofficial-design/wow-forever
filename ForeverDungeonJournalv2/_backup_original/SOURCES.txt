2026-09-25 v1.0.16 portrait / item-quality regression fix
==========================================================
- v1.0.15 did not restore the old zoning portrait warmup; the PLAYER_ENTERING_WORLD
  portrait path remained direct-only. The new synchronous work in v1.0.15 was the
  hidden tooltip quality-color scan. That scan has been removed.
- Item row colors now prefer the live client's numeric item quality (GetItemInfo /
  C_Item.GetItemQualityByID) and only request data for items currently being shown.
  Known Forever exceptions remain explicit: Deviate Hide Pack common, Fel Steed
  Saddlebags uncommon, Snakeskin Bag uncommon, Small Sack of Gems common.
- v1.0.14's direct-only portrait conversion could leave Forever-exclusive bosses as
  question marks on a fresh install because Ruins of Lordaeron / Hall of Thanes do
  not always expose a usable Encounter Journal displayInfo. v1.0.16 keeps all known
  portraits direct 2D but adds a one-time lazy fallback for an unknown Forever NPC:
  it resolves only while the boss page is visible, saves the display ID, clears the
  PlayerModel immediately, and is hard-cancelled on PLAYER_LEAVING_WORLD.
- Follow-up quest rewards in Notes now use the same icon/name item cards and full
  hover tooltips as normal quest rewards instead of text-only colored links.
